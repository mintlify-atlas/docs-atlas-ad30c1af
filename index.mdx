Backstage Assistants adds a fully integrated AI chat experience to your developer portal. Every answer is grounded in your catalog and TechDocs — no hallucinated facts about your systems. Every Backstage action runs with the permissions of the person asking, so the assistant can look up entities, search docs, or kick off a scaffolder template on their behalf.

## What it does

Backstage Assistants is four npm packages that wire together into your existing Backstage app. The frontend plugin adds a chat page at `/assistants`, a floating panel that opens beside any page, and a homepage composer. The backend plugin streams replies, runs Backstage actions as the calling user, and connects to external MCP servers. An optional semantic search module indexes everything Backstage search crawls into a pgvector knowledge base.

## Packages

Backstage Assistants ships as four packages. Install the first two to get started; the others are optional.

| Package | Purpose |
|---|---|
| `@drewswiredin/backstage-plugin-assistants` | Frontend plugin — chat page, panel, homepage composer, admin editor |
| `@drewswiredin/backstage-plugin-assistants-backend` | Backend plugin — model loop, action tools, MCP servers, API |
| `@drewswiredin/backstage-plugin-assistants-common` | Shared types and permissions (installed transitively) |
| `@drewswiredin/backstage-plugin-assistants-backend-module-semantic-search` | Optional semantic + fuzzy + keyword knowledge index |

## Requirements

<Note>
Backstage Assistants requires the **new** Backstage frontend system (`createApp` from `@backstage/frontend-defaults`) on Backstage 1.56 or later. It does not mount in a legacy `packages/app` built on `@backstage/app-defaults`.
</Note>

- Backstage 1.56+ with the new frontend and backend systems
- Node 22.12 or later
- React 18 and `react-router-dom` ^6.30.2
- A plugin database: SQLite, Postgres, or MySQL
- A model provider API key: OpenAI, Anthropic, Azure OpenAI, or any OpenAI-compatible endpoint
